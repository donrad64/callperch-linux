# Changelog

## 1.3.0 — 2026-10-10

- Add the free ten-callsign comparison workspace, matching Mac scoring, with personal ratings, priorities, named comparisons, CSV export, local audio and QSL/plate previews.
- Add snapshot-age reminders, selected-license previous-callsign links, expiration/cancellation wording, loading feedback and acknowledgments.
- Stage sync ZIP downloads beside the local database instead of /tmp; report the actual storage folder and clean up downloads after each operation.
- Document Linux voice quality and optional standalone Piper voice downloads; the app continues to use eSpeak.
- Expand synthetic backend/Qt checks and build native x86-64/ARM64 packages on packaging pull requests.
