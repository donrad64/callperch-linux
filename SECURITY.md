# Security reporting

Security fixes target the latest Linux release and current main branch. Older versions are not maintained separately.

Please report suspected vulnerabilities privately to hamradio.balancing125@simplelogin.com or kr4goj@arrl.net. Include the version, architecture, relevant behavior, impact, and a minimal reproduction using synthetic data. Do not open a public issue with exploit details, credentials, private addresses, databases, or real FRNs. If additional information is needed, the maintainer will reply; no response-time guarantee is made.

CallPerch imports untrusted FCC ZIP records locally. Relevant areas include archive bounds, parser behavior, subprocess execution, database atomicity, links, and public-record disclosure. Please allow time to investigate and coordinate a fix before publishing details.
